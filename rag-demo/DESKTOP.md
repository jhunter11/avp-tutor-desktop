# Present the RAG demo

Download **avp-rag-presentation.zip** from this repository's latest GitHub release and extract it first. The ZIP includes the built page, the 134-second 1080p video, captions, source code, corpus and saved vectors. Use a local folder, not the ZIP preview.

Install **64-bit Python 3.11**. Initial setup needs internet to install Python packages and download the pinned MiniLM embedding model. No API key, GPU, Node or Manim is needed for the presentation ZIP. Setup can take several minutes; do it before the call.

## Windows

Open the extracted `rag-demo` folder. Double-click **Setup-RAG.cmd** once. After it passes, double-click **Start-RAG.cmd** and keep that window open.

Or use PowerShell in that folder:

```powershell
py -3.11 desktop.py setup
py -3.11 desktop.py run
```

## macOS or Linux

From the extracted `rag-demo` folder:

```sh
python3.11 desktop.py setup
python3.11 desktop.py run
```

Open **http://127.0.0.1:5192/** in Chrome and share that tab or window in the call. Run setup once; later runs use the cached model without network access. Keep this folder and its `.venv` in the same location after setup. Stop with Ctrl+C. Ports 5192 and 8783 must be available.

## Three-minute demonstration

1. Use **For-loop syntax**. Show the source ID, exact AVP excerpt and similarity score in Sources.
2. Select **Vector**. Compare the question with a retrieved passage. The score uses all 384 components; similarity does not prove that a source answers the question.
3. Select **Watch walkthrough**, play the captioned video, then use **Back to live sources**. Leaving pauses it and keeps the chat.
4. Ask a new AVP question. Explain that this is real local vector retrieval with exact source extraction. The answer is not generated by a live LLM.

If setup cannot finish before the meeting, play `public/media/avp-rag-walkthrough.mp4` directly. Captions and narration are in `animation/captions.srt` and `animation/DIRECTOR_SCRIPT.md`. The video is recorded output; do not present it as a live request.

## Limits and next work

The developer-authored diagnostic set retrieved expected sources for 15/15 supported questions, quoted them for 12/15, and declined 5/9 unsupported questions. These are local diagnostics, not a human-learning study. See [accuracy notes](docs/ACCURACY.md). Corpus review, coverage and support checks remain necessary.

The old frontend is at the repository root. To demonstrate its RAG bridge, keep the RAG presentation running, then follow [the integration setup](../docs/tutor/RAG_DEMO.md). It keeps `POST /api/tutor` fixed. In offline mode the bridge sends only the question to retrieval and displays extracts; it does not analyze the supplied code or screenshots.

## Using a source clone

The GitHub source clone includes the final video but does not include the built `dist` page. Install Node 22 as well as Python 3.11. `desktop.py setup` runs `npm ci --ignore-scripts` and `npm run build` if the page is absent. The release ZIP already contains that page.

Setup uses [Python virtual environments](https://docs.python.org/3.11/library/venv.html) and a [pinned Hugging Face model download](https://huggingface.co/docs/huggingface_hub/guides/download). Inference stays local and offline.
